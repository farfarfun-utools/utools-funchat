言来语往 UPXS 正式版，官方插件项目 ID：`zc8khhsw`。

本版修复部分系统从文件管理器复制 PDF 后，粘贴到聊天框只出现文件名的问题：插件会读取系统剪贴板中的文件路径和 PDF 内容，再让用户选择提取文字或按页面图片识别。若系统未提供可读取的文件格式，界面会提示使用拖入或文件选择。

下载 `utools-funchat-1.0.3.upxs` 后导入 uTools。此包通过 GitHub Actions 构建，使用统一的 `utools-devtools` 生成，并完成认证解密、清单资源、插件 ID 和 ASAR 完整性校验；提供 `SHA256SUMS` 核对下载文件。

三个敏感字段由组织 Secrets 注入，仓库只保存公开的项目配置。相同打包链路已由用户在 FunCalc 上实机安装验证；本插件自身的安装和功能仍待实机确认。
